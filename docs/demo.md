The quadrotor comparison uses combined-scenario seed 46; the Go2 comparison uses combined-scenario seed 45 and shows a selected STGP instability case. These are illustrative recordings, not an aggregate over all seeds. The method panels replay independently recorded trials. Real-world footage demonstrates hardware experiments whose acquisition and execution code are outside this simulation release.
